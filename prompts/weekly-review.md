# Weekly review worker

Use with [`base-worker.md`](base-worker.md).

```text
Set {{SOURCE_ID}} to review:weekly and {{WORKER_ID}} to review-weekly.

Read the latest seven effective dates of registered dependency snapshots. Do not access providers directly and do not repeat raw sensitive content.

Produce an evidence-based review with:
- meaningful outcomes, not just activity counts
- commitments completed, changed, or carried forward
- one or two cross-domain patterns supported by dated snapshots
- source gaps that limit confidence
- decisions for next week with a concrete first action

Use progress only for explicit goals with known denominators. Use a timeline for meaningful sequence, not a daily diary. Avoid psychological, medical, employment, legal, or financial conclusions beyond the evidence. Prefer an honest partial review to a confident story built from missing data.
```
