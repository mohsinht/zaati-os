# Governance

Zaati OS uses lightweight maintainer governance during the `0.x` series.

## Decision priorities

1. Prevent user-data exposure.
2. Preserve provider and hosting portability.
3. Keep contracts understandable and versioned.
4. Improve daily usefulness and accessibility.
5. Minimize maintenance and deployment burden.

Maintainers may merge routine changes after review and passing checks. Changes to privacy boundaries, licensing, telemetry, hosted services, snapshot compatibility, or the audited UI block set require a public proposal and explicit maintainer approval.

Security fixes may be developed privately and released before full public discussion.
