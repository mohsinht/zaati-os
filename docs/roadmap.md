# Roadmap

## 0.1, foundation

Snapshot contracts, adaptive rendering, synthetic demo, starter prompts, private deployment boundary, theming, CI, and contribution model.

## 0.2, workflow ergonomics

Provider-specific setup recipes, improved source scaffolding, migration helpers, retention tooling, and more failure-state fixtures.

## 0.3, domain ecosystem

Composable community domain packs, compatibility tests, pack discovery metadata, and an entirely synthetic gallery.

## 0.4, durable context

Daily, weekly, and monthly aggregation helpers, evidence graphs, change detection, and export controls.

## 1.0 criteria

A new user can configure three sources, run any supported LLM workflow, deploy behind authentication, understand failure states, add a fourth domain without changing core code, and upgrade contracts without losing private history.

Hosted ingestion, maintainer analytics, automatic high-stakes decisions, and any feature that requires upstream access to user data remain outside the roadmap.
